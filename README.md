# tyler-s-warehouse

Snapshot of skills and plugins in use on 2026-08-28 (Asia/Shanghai).

This repo is a backup of agent skills (`SKILL.md` packages) plus an inventory of installed Cursor plugins/connectors. It is **not** a republication of full plugin source trees. Connector credentials are not included.

## Layout

- `skills/cursor-managed/` — Cursor-managed skills (read-only in the app)
- `skills/plugins/<plugin>/` — skills that shipped with installed plugins
- `plugins/installed.json` — installed connectors/plugins and auth status at snapshot time
